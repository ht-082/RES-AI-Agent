# RES AI Agent — 재생에너지 사업개발 AI 어시스턴트

> 사내 문서를 근거로 답하는 RAG 챗봇 + 사업 관리 대시보드.
> 태양광 발전사업 6개(홍성·당진1·당진2·임자·안면도·태평)의 계약서·허가증·보고서·재무모델
> **약 400건, 청크 18,823개**를 검색해 출처와 함께 답변한다.

## 무엇을 할 수 있나

**① 사내 문서 챗봇** — "당진행복솔라 PF 대주단 구성을 표로 보여줘"
- 문서 원문 청크를 근거로 답하고, **참조한 원문을 출처 칩으로 표시** (근거 없는 답변 차단)
- 표·차트·타임라인·관계도 등 **요청한 형식으로 가시화**
- 웹 검색(Tavily) 병용 옵션, 대화별 모델 선택(Terra/Sol/Luna)

**② 사업 관리 대시보드** — 사업지 25개소의 인허가 단계·예산·이슈를 한눈에

**③ 확장 중** — 계약서 생성·검토, 재무모델 (팀원 병렬 개발)

## 어떻게 만들었나 (기술 구성)

```
문서 405건 ─▶ 파싱(hwp·pdf·xlsx·docx / 스캔본은 GPT 비전 OCR)
          ─▶ 유형별 규칙 청킹(계약=조항, 법령=조문, 재무모델=핵심 시트만)
          ─▶ BGE-M3 임베딩(로컬) + 컨텍스트 헤더 [사업: X] [문서: Y] 주입
          ─▶ Qdrant 하이브리드 검색 → 리랭킹 → 관련성 게이트 → GPT-5.6 답변
```

- **스택**: Django 5 · React 18 · PostgreSQL 16 · Qdrant · Docker Compose
- **정확성 장치**: 청크 규격 자동 검증(위반 시 문서 거부), 결정적 청크 ID(재적재 안전),
  근거 없으면 "자료에 없습니다"로 답하는 게이트
- **품질 개선 실증**: 리랭커에 문서 컨텍스트 주입 → 정답 문서가 꼴찌(0.117)에서 1위(0.835)로

## 협업 인프라 (팀 확장 준비 완료)

| 항목 | 내용 |
|---|---|
| 코드 공유 | GitHub (`ht-082/RES-AI-Agent`) — 클론 후 문서대로 30분 내 구동 |
| DB 재현 | baseline 백업·복원 스크립트 — 팀원 전원 동일한 데이터 상태 |
| **공용 벡터 서버** | AWS EC2 + HTTPS — 팀원은 `.env` 두 줄로 접속, 재임베딩 불필요 |

| 협업 규칙 | 파일 소유 경계·커밋 규율·DB 마이그레이션 규칙 문서화 |

## 개발 여정 하이라이트

- 코퍼스 v1(10,777청크) → **v2(18,823청크)** 전면 재적재 — 파일명 체계화 405건,
  hwp 표 추출 복원, 스캔본 68건(1,017페이지) OCR, 사업개요 정리본 6건 신규 작성
- OCR 모델을 GPT-5.6으로 통일 — 4o-mini의 한글 고유명사 오독("당진행복솔라"→"슬래브") 실측 후 폐기
- 검색 실패 사례를 파고들어 리랭커 개선·질문 가이드 도출 (실사용 피드백 루프)
