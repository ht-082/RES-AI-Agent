# 문서 종류별 청킹(Chunking) 전략 가이드

이 문서는 재생에너지 RAG 에이전트 내에서 문서의 종류별로 텍스트를 분할(Chunking)하고 메타데이터를 추출하는 핵심 규칙을 정의합니다. 
관련 소스 코드는 `backend/apps/rag/chunkers.py`에 구현되어 있습니다.

---

## 1. 일반 문서 (General)
특정 양식이나 구조가 뚜렷하지 않은 일반적인 텍스트 문서를 기계적으로 분할하는 기본(Fallback) 방식입니다.

* **함수명**: `chunk_general`
* **분할 기준**: 단순 글자 수 (최대 800자 제한)
* **오버랩(Overlap)**: 분할된 청크 간의 문맥 단절을 방지하기 위해 앞뒤로 150자씩 겹치도록 자릅니다.
* **메타데이터**: `{'doc_type': 'general'}`

## 2. 계약서 (Contract)
법적 효력이 있는 계약서 문서를 조항(Article) 단위로 분리하여 문맥을 보존하는 방식입니다.

* **함수명**: `chunk_contract`
* **분할 기준**: 정규식 패턴(`제 N조`)을 기반으로 전문(Preamble)과 본문 조항을 나누어 자릅니다.
* **추가 처리**: 
  - 각 조항의 텍스트가 1500자를 초과할 경우, 내부적으로 다시 1200자 단위(오버랩 150자)로 하위 분할합니다.
* **메타데이터 추출**:
  - `doc_type`: `contract`
  - `article_no`: 조항 번호 (예: `제5조`)
  - `article_title`: 조항 제목이 괄호/대괄호 안에 있는 경우 추출 (예: `임대기간`)

## 3. 법령 및 규정 (Law)
법령 구조를 분석하여 시행일 등 법률적 맥락이 섞이지 않도록 신구조문을 구분하는 방식입니다.

* **함수명**: `chunk_law`
* **분할 기준**: 계약서와 동일하게 정규식을 사용하여 `제 N조` 조문 단위로 자릅니다.
* **추가 처리**: 
  - `[시행일 2024. 1. 1.]` 형태의 날짜 패턴을 탐지합니다.
  - 해당 조문이 1500자를 초과하면 1200자 단위(오버랩 150자)로 하위 분할합니다.
* **메타데이터 추출**:
  - `doc_type`: `law`
  - `law_title`: 법령명 (파일명 기준)
  - `article_no`: 조항 번호
  - `version`: 현재 시행 중이면 `current`, 미래 시행 예정(시행일 존재)이면 `future`로 구분
  - `effective_date`: 시행일이 존재할 경우 해당 날짜 추출

## 4. 보고서 및 발표자료 (Report)
PPT, PDF 보고서 등 슬라이드 형태의 문서 구조를 반영하기 위한 방식입니다.

* **함수명**: `chunk_report`
* **분할 기준**: 문서 파싱 단계에서 식별된 **페이지/슬라이드 단위**로 일차 취합합니다.
* **추가 처리**: 
  - 페이지 내의 전체 텍스트 중 첫 번째 줄을 해당 페이지의 주제(슬라이드 제목)로 간주합니다.
  - 해당 페이지 텍스트가 1500자를 초과하면 1200자 단위(오버랩 150자)로 하위 분할합니다.
* **메타데이터 추출**:
  - `doc_type`: `report`
  - `page_no`: 페이지 번호
  - `slide_title`: 추출된 슬라이드의 첫 번째 줄 텍스트 (최대 100자)
