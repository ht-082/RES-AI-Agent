# RES-AI-Agent 협업 작업 규칙

> 이 저장소는 **여러 Claude Code 대화·개발자가 동시에** 작업한다
> (RAG 챗봇 / bizdev 대시보드 / 계약서·재무모델). 아래 규칙은 서로의
> 미완성 작업을 실어 나르거나 깨뜨리는 사고를 막기 위한 것이다.
> 실제 사고 사례에서 나온 규칙이며, 전 대화·전 인원 공통 적용이다.

## 1. 파일 소유 경계

| 영역 | 소유 경로 |
|---|---|
| RAG 챗봇 | `backend/apps/{rag,chat,documents,accounts,workspaces}` · `backend/services` · `frontend/src/features/{chat,auth}` |
| bizdev 대시보드 | `backend/apps/bizdev` · `frontend/src/features/ops` |
| 계약서·재무모델 | `backend/apps/contracts` · `frontend/src/features/{contracts,finance}` |
| **공유(전원 최소 수정)** | `backend/config/settings.py` · `backend/config/urls.py` · `frontend/src/App.tsx` · `frontend/src/index.css` · `frontend/package.json` · `db/schema.sql` · `docker-compose.yml` |

- 자기 영역 밖 파일은 **읽기만** 한다. 고칠 게 보이면 소유 대화/담당자에게 전달.
- 공유 파일은 **자기 앱 등록·라우트 추가 등 최소 diff**만. 구조 변경은 사전 합의.

## 2. 커밋 규율 (가장 중요)

- **`git add -A` / `git add .` 금지.** 반드시 자기 파일을 경로로 명시해 add 한다.
  이유: 같은 순간 다른 대화의 미커밋 작업물이 워킹트리에 섞여 있다. `-A`는
  그걸 통째로(또는 반쪽만) 실어 날라 원격을 깨뜨린다 — 실제로 날 뻔했다.
- 기능이 한 단위 돌아가면 **바로 커밋**한다. 미커밋 상태를 하루 이상 끌지 않는다.
- **push 전 3초 점검**: `git status --short` 로 스테이징 목록에 남의 경로가 없는지,
  공유 파일 diff 에 자기 변경만 있는지 (`git diff --cached backend/config/settings.py`).
- push 전 `git pull --rebase` 먼저. 충돌 나는 파일이 남의 소유면 **임의 해소 금지**.
- 커밋 메시지에 영역 접두 권장: `feat(bizdev): …` / `fix(rag): …` / `feat(contracts): …`

## 3. DB·마이그레이션 규칙

- **`makemigrations` 는 반드시 앱 이름을 지정한다** (`makemigrations bizdev`).
  이름 없이 돌리면 다른 앱의 잠복 드리프트까지 끌려 나온다.
- 자동 생성된 마이그레이션이 **자기 앱 밖 테이블**이나 **DROP/Remove** 를
  포함하면 적용 전에 멈추고 확인한다. 이 저장소는 `db/schema.sql`(initdb 원본)과
  마이그레이션을 병행해서, 자동 생성이 파괴적 연산을 제안하는 일이 실제로 있다
  (사례: contracts 0003 — DROP 대신 SeparateDatabaseAndState 로 직접 작성).
- **users 를 참조하는 FK**: 기존 테이블(schema.sql 정의)은 `db_column='created_by'`
  명시가 관행. 신규 테이블(마이그레이션 전담, bizdev 등)은 Django 기본(`*_id`)을
  그대로 쓰되 schema.sql 에 손으로 추가하지 않는다 — bizdev 는 마이그레이션 전담이다.
- RAG 쪽 테이블(`documents`·`document_chunks`·`corpus_versions`·`projects`·
  `workspaces`)은 **읽기 전용으로 참조만** 한다. 스키마 변경은 RAG 담당과 합의.
- `reset_db.py` 류 전체 삭제 스크립트 실행 금지 (코퍼스 롤백본까지 날아간다).

## 4. 환경·설정

- 비밀 값은 `backend/.env` 하나가 단일 출처다. **어떤 파일에도 키를 하드코딩하지
  않는다** (커밋 전 스캔이 있지만 애초에 넣지 않는 게 규칙).
- 새 환경변수를 추가하면 `.env.example` 두 곳(루트·backend)에 **같은 커밋으로** 반영.
- LLM 은 `gpt-5.6-terra` 로 통일돼 있다. gpt-5.x 는 `temperature=0` 거부,
  `max_tokens` 대신 `max_completion_tokens` — 4o 계열로 임의 변경 금지.
- 새 파이썬 패키지는 `backend/requirements.txt` 에 추가 후 이미지 재빌드까지 확인.
